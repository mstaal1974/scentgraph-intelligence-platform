# Roadmap

1. **Foundation:** supplier-first ingestion, layered schema, matching, review workflow, licensing guardrails, typed API, and tests.
2. **Profile drafts (current):** deterministic supplier/candidate profile generation, confidence, provenance notes, human approval/rejection, and no automatic catalogue promotion.
3. **Data operations:** persistent API repositories, curator queues, taxonomy governance, profile versioning, and audited catalogue promotion.
4. **Independent enrichment:** permitted-source verification, original descriptions, calibrated vectors, reviewed clone estimates, contextual recommendations, and Scentprint feedback.
5. **Commercial API:** tenant identity, scoped keys, quotas, metering, audit logs, data tiers, and SLAs.
6. **Channels:** retailer enrichment tools and optional white-label/Shopify/WooCommerce consumers.
7. **Operations:** security review, privacy controls, observability, backups, and regional production deployment.
